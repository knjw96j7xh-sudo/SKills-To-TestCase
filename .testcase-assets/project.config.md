## 业务域列表

> LLM 在生成用例和选择检查点时，将优先从以下业务域中匹配分类。

| 域标识 | 中文名称 | 说明 |
|--------|----------|------|
| UC | 用户中心 | 注册、登录、找回密码、账号设置 |
| PAY | 支付 | 充值、提现、订单支付、退款 |
| LIST | 数据列表 | 通用列表、分页、搜索、筛选 |
| FILE | 文件管理 | 上传、下载、预览、删除 |
| RISK | 通用风险 | 并发、网络异常、权限越界 |
| API | 接口层 | 参数校验、鉴权、幂等性 |
| SUPPLY | 供应链协同 | 品牌方与供应商之间的任务下发、催报、数据联动 |

> [!NOTE]
> 新增业务域时，同步在 checkpoints-index.md 中新增对应分类，并在此表追加一行。

## 默认行为配置

| 配置项 | 当前值 | 说明 |
|--------|--------|------|
| 用例ID前缀 | TC | 生成用例时的编号前缀 |
| 默认优先级规则 | P0=异常场景（阻断性错误），P1=正向主流程/边界，P2=并发，P3=体验类 | LLM 分配优先级的参考 |
| 历史文件是否 Git 追踪 | 否（已加入 .gitignore） | 改为「是」则从 .gitignore 中删除对应规则 |
| 评审默认应用维度 | COMP-01,COMP-02,COMP-03,EXEC-01 | 每次评审时默认勾选的评审点 |
